# Happy Birthday 🎂

A tiny React (Vite) birthday page, hosted on GitHub Pages.

## Pictures

Drop `.jpg`, `.png`, `.gif` or `.webp` files in `photos/`. They float across the page at random and are picked up automatically on the next build.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Push this folder to a GitHub repo (branch `main`).
2. In the repo go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` builds and deploys the site automatically.

The site will be at `https://<your-username>.github.io/<repo-name>/`.
